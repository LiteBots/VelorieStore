System licencji

Każdy zakup chroniony kluczem licencji

Twórcy wbudowują weryfikację w swój kod. Klient wkleja klucz do configu, a Velorie pilnuje limitu serwerów i unieważnia klucze z wycieków.

  • Limit serwerów na licencję
    Aktywacje resetujesz jednym kliknięciem przy zmianie hostingu.
  • Gotowe integracje
    Java (Spigot/Paper), Lua (FiveM), JavaScript i Python.
  • Darmowe aktualizacje
    Nowe wersje trafiają od razu do biblioteki kupujących.

-- Weryfikacja licencji Velorie
local key = GetConvar('velorie_license', '')

PerformHttpRequest(API, function(status, body)
  local data = json.decode(body)
  if not data.valid then
    StopResource(GetCurrentResourceName())
  end
end, 'POST', json.encode({ license_key = key }))

Najczęstsze pytania

Czym jest licencja i jak ją aktywować?

Każdy zakup generuje unikalny klucz przypisany do Twojego konta. Wklejasz go do configu produktu — przy starcie serwera zasób sprawdza klucz przez API Velorie. Limit serwerów ustala twórca, a aktywacje resetujesz w panelu.

Czy aktualizacje są płatne?

Nie. Po zakupie zawsze pobierasz najnowszą wersję pliku z biblioteki, a w zakładce „Aktualizacje” widzisz pełny changelog.

Jakie metody płatności są dostępne?

Karta płatnicza, BLIK i szybkie przelewy obsługiwane przez bezpieczną bramkę płatności. Nie przechowujemy danych kart.

Co jeśli produkt nie działa?

Skontaktuj się z twórcą przez jego profil lub Discord. W przypadku sporu nasz zespół pomoże rozwiązać problem.

Ile kosztuje sprzedaż na Velorie?

Wystawianie produktów jest darmowe. Pobieramy prowizję tylko od sprzedaży, a resztę wypłacasz z panelu twórcy. Szczegóły na stronie Dla twórców.

Tworzysz dla społeczności? Sprzedawaj u nas.

Płatności, dostawa plików, licencje i statystyki — gotowe od pierwszego dnia. Ty skupiasz się na tworzeniu.
