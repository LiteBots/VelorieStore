API licencji

Każdy zakup w Velorie Store generuje unikalny klucz VEL-XXXX-XXXX-XXXX-XXXX. Twój plugin, skrypt lub mod sprawdza go przy starcie. Jeśli klucz jest nieważny, unieważniony albo przekroczono limit serwerów — zasób się wyłącza.

Bez klucza API

Endpoint weryfikacji jest publiczny — nie musisz przechowywać sekretów w kodzie.

Limit serwerów

Każdy nowy identyfikator serwera zużywa jedną aktywację licencji.

Unieważnianie

Klucz z wycieku wyłączasz jednym kliknięciem w panelu twórcy.

Weryfikacja klucza

Wywołaj przy starcie zasobu (i opcjonalnie cyklicznie, np. co 6 godzin).

POST
ParametrTypOpis
license_keystringKlucz klienta. wymagany
product_idnumberID produktu z panelu twórcy. Zalecany — blokuje użycie klucza kupionego do innego produktu.
identifierstringStały identyfikator serwera (np. IP:port, adres cfx.re). Domyślnie adres IP.

Odpowiedzi i błędy

API zawsze zwraca status 200 z polem valid — łatwo to obsłużyć w każdym języku. Status 429 oznacza przekroczenie limitu 120 zapytań na minutę.

{
  "valid": true,

    "max_activations": 2
  }

Licencja odrzucona
{
  "valid": false,
  "reason": "activation_limit",
  "message": "Osiągnięto limit aktywacji (2)."
}
reasonZnaczenie
missing_keyNie przesłano klucza.
not_foundKlucz nie istnieje.
wrong_productKlucz należy do innego produktu niż product_id.
revokedTwórca unieważnił licencję.
activation_limitWykorzystano limit serwerów — klient może zwolnić aktywacje w panelu.

Zwolnienie aktywacji

Wywołaj przy trwałym wyłączeniu serwera, aby zwolnić miejsce w limicie.

POST

Parametry: license_key, identifier.

Dobre praktyki

          

            
Weryfikuj po stronie serwera
W FiveM tylko w server.lua. W Javie zaciemnij kod (np. ProGuard).

            
Cache na wypadek awarii
Zapamiętaj ostatni poprawny wynik i pozwól na start przez 24 h, jeśli API jest nieosiągalne.

            
Informuj o aktualizacjach
Porównaj latest_version z wersją zasobu i wypisz komunikat w konsoli.

            
Stały identyfikator
Używaj wartości, która nie zmienia się przy restarcie — inaczej klient szybko wyczerpie limit.
